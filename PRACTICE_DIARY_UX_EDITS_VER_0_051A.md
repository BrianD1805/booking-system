# Booking System Ver-0.051A — Practice Diary UX Edits

## Summary
Refines the admin Practice Diary desktop layout after Ver-0.051.

## Changes
- Moves the ZipBook logo/version into the signed-in admin top bar, centred by the full screen width between the signed-in identity and Admin menu.
- Removes the separate admin header logo block from admin pages because the logo now lives in the top bar.
- Increases the Practice diary heading by roughly 20% and gives it a slightly stronger heading weight without returning to the previous heavy title style.
- Keeps the selected diary date next to Practice diary and adds the current time.
- Places the Date selector, Practitioner dropdown, Active clinicians, Upcoming bookings and Open slots remaining into one compact row on desktop.
- Adds the selected date and current time next to the Slots view title so it remains visible near the live diary area after scrolling.
- Makes the Practice Diary date picker open like the custom practitioner dropdown, anchored under the control instead of shifting/overlaying awkwardly.

No SQL required.
